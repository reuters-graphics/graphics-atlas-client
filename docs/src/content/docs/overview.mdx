`@reuters-graphics/graphics-atlas-client` is a global country **metadata** client based on the [ISO 3166 country codes](https://www.iso.org/iso-3166-country-codes.html), with translations for country and UN region names in German, French, Italian, Spanish, Portuguese, Japanese, Chinese and Persian.

TopoJSON geometry (country **polygons** and border **lines**, at `low`/`medium`/`high` detail) ships with this package (generated at publish time). Use it two ways: fetch it on demand from the CDN via the client's `fetch*` methods, or import files directly for a tree-shakeable local bundle — see [TopoJSON maps](../topojson/).

## Install

```bash
pnpm add @reuters-graphics/graphics-atlas-client
```

The package ships **dual ESM + CommonJS** and has **no runtime dependencies**.

```js
import AtlasMetadataClient from '@reuters-graphics/graphics-atlas-client';
const client = new AtlasMetadataClient();
```

## At a glance

- **6** UN regions, **22** subregions, **249** countries &amp; territories.
- Lookups by name, slug or ISO code (alpha-2 / alpha-3 / numeric) — case-insensitive.
- Each country carries translations, abbreviations, `[lon, lat]` `coordinates`, and a `dataProfile` (population, GDP + income group).

## Data sources

- Geometry: built in-package from [`country-borders`](https://github.com/reuters-graphics/country-borders) ([Overture Maps](https://overturemaps.org/), ODbL — © OpenStreetMap contributors, Overture Maps Foundation)
- Population: [World Bank](https://data.worldbank.org/indicator/SP.POP.TOTL) (SP.POP.TOTL)
- GDP: [World Bank](https://data.worldbank.org/indicator/NY.GDP.MKTP.CD) (NY.GDP.MKTP.CD, current US$)
- Translations: [umpirsky/country-list](https://github.com/umpirsky/country-list)
